Parts overview

The Parts view lists every part of every appliance in 1 place. It shows the low parts and the parts that wear out. A user does not need to open each appliance.

The view is a mode of the Appliances tab. It reads the same data as the Parts tab of an appliance page. It does not change a service. It does not change an event. It does not change a setting.

Open the Parts view​

  1. Open the Appliances tab.
  2. Select Parts in the Appliances | Parts switch.

The address of the view is /home-keeper/appliances/parts. Select Appliances to go back to the list of appliances. The panel keeps the last mode in this browser. The Appliances tab opens in that mode.

Read a row​

ColumnContent
PartThe name with the part number and the vendor. The cost shows below. The name links to the appliance page.
Typeconsumable or wear item.
StockThe stock stepper. It has the same controls as the Parts tab of an appliance page.
Reorder atThe stock level at which the part is low.
StatusLow stock shows a low part. In stock shows a part above its reorder point. Not counted shows a part with no stock number.
Next dueThe due date of the task that replaces a wear item. For a wear item that counts uses this is the use count.

A part is low when its stock is at or below its reorder point. Parts without a stock number have the status Not counted and are never low.

If a low part has a Buy task then the Status column has a Buy link. The link opens the Buy task. A low part with no Buy task has no link.

Each tap on − or + is 1 stock change. The change is the same one that the appliance page makes. It can create a Buy task or end one. This is the same as on the appliance page.

Find parts​

The chips above the list filter the parts. Each chip shows a count.

  • All shows every part.
  • Low stock shows the low parts.
  • Wear items shows the parts of type wear item.
  • Not counted shows the parts with no stock number.

The counts follow the Search box and the scope. They do not follow the chip.

These controls arrange the list.

  • Search matches the name and the part number. It also matches the vendor and the appliance name.
  • Group by is Appliance or Type. The default is Appliance.
  • Sort by is Name or Stock or Last replaced.

Stock puts the lowest stock first and the parts with no count last. Last replaced puts the oldest date first and the parts that were never replaced last.

The panel keeps the chip and the group and the sort in this browser. They are not a setting of the user.

Archived appliances​

The view hides the parts of archived appliances. Select Archived in the scope to show them. Select Active to go back.

Appliances that an integration owns​

The parts of an appliance that an integration owns show in the view. An example is the battery pool. An admin can change the stock of these parts. The integration locks the name of the appliance.

Users who are not admins​

Only an admin can change stock. A user who is not an admin sees the same list. The stock is text. The list has no stepper. The backend refuses a stock change from a user who is not an admin.

Add a part​

The Parts view has no Add part button. A part belongs to an appliance. To add a part open the appliance. Open its Parts tab. Select Add part. See Parts and wear items.
